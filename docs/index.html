전사 전략 & 시나리오 플래닝 OS

전략-KPI 목표, 시나리오 수지 예측 및 거버닝 AI를 하나의 오프라인 시스템으로 통섭

Planexus는 외부 인터넷이 차단된 폐쇄망 인프라 환경에서 비전-전략목표-KPI 추적, 프로젝트 포트폴리오, 결정론적 수지 시뮬레이션, Excel 임포트/롤백, Keycloak OIDC SSO 및 사내 AI 코파일럿을 위한 Streamable HTTP MCP를 단일 Docker 컨테이너로 완벽 통합 제공합니다.

주요 기능

전략 목표 수립부터 수지 시뮬레이션, 거버닝 AI 및 오프라인 보안까지 통합 제공합니다

🎯

전략-KPI-포트폴리오 통섭

전사 비전부터 사업부별 KPI, 프로젝트 포트폴리오까지 단일 가치 체계로 연결하여 기획 수공수를 대폭 절감합니다.

🔮

결정론적 시나리오 시뮬레이션

낙관, 기본, 비관 수지 시나리오를 실시간 재계산하고 승인 워크플로우 및 Excel 롤백을 지원합니다.

🛡️

사내 거버닝 AI 연동

사내 보안 방화벽 내부의 LLM 모델과 연결하여 민감한 기업 전략 데이터의 외부 유출 없이 AI 질의응답을 수행합니다.

🔐

Keycloak OIDC & Break Glass

Keycloak OIDC (PKCE) SSO와 네트워크 단선 상황을 대비한 삭제 불가능한 Break Glass 부트스트랩 계정을 탑재했습니다.

🤖

Streamable HTTP MCP Server

Claude Desktop, Cursor 등 AI 에이전트가 호출자의 권한 범위 내에서 안전하게 실시간 KPI 달성률과 예산을 분석합니다.

📦

오프라인 단일 Docker

Go 백엔드와 React 19 / MUI 자산이 통합된 단일 non-root Docker 이미지로 외부 CDN 연결 0% 폐쇄망 배포를 보장합니다.

개발자 API & Streamable MCP

오프라인 설치 가이드

단일 Docker 이미지로 오프라인 폐쇄망 환경에 빠르게 배포하세요

🐳 Single Docker Archive Load

GitHub Release의 .tar.gz 패키지 하나만 오프라인망으로 반입하여 구동합니다.

docker load < planexus-v1.0.0.tar.gz

# 4개 필수 환경변수로 구동
export POSTGRES_DSN='postgres://planexus:password@postgres:5432/planexus'
export BOOTSTRAP_ADMIN='admin'
export BOOTSTRAP_ADMIN_PASSWORD='change-this-strong-password'
export ENCRYPTION_KEY='Base64Encoded32ByteKeyHere=='
docker compose up -d

⚙️ 4대 필수 환경변수

Planexus 기동에 필요한 환경변수는 오직 4개입니다.

POSTGRES_DSN=postgres://planexus:pass@localhost:5432/planexus
BOOTSTRAP_ADMIN=admin
BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!
ENCRYPTION_KEY=Base64Encoded32ByteKeyHere==

자주 묻는 질문 (FAQ)

네. 외부 CDN, 외부 폰트, 외부 API 다운로드가 일절 없으며, 백엔드와 프론트엔드가 단일 Docker 컨테이너로 통합 패키징되어 100% 오프라인 구동합니다.

네. Excel/XLSX 일괄 가져오기 기능 및 파싱 오류 시 원클릭 버전을 이전 상태로 롤백하는 무결성 롤백 엔진을 제공합니다.

`openssl rand -base64 32` 명령으로 생성된 32바이트 암호화 키를 전달하며, DB 내 암호화된 시크릿을 AES-256-GCM 표준으로 안전하게 지킵니다.
